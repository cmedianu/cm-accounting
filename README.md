# cm-accounting

Claude Code skills for small-business bookkeeping in Canada.

| Skill | What it does |
|---|---|
| [gst-quick-method](skills/gst-quick-method/) | Quarterly GST/HST Quick Method (GST34) workbook: invoices from a pasted screenshot, capital-purchase ITCs from a pasted receipt, and the CRA return fields in screen order, independently cross-checked. Needs only uv and Excel; runs on Windows, macOS and Linux. |

Financial data never goes in this repository. `.gitignore` blocks spreadsheets, exports,
screenshots and JSON. The only exception is the fictional example images in `skills/*/images/`.

Not tax or accounting advice: you are responsible for everything you file; check the numbers before filing.
